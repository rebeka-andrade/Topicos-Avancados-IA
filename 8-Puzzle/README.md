# 8-Puzzle — Busca em Largura (BFS)

Implementação do problema 8-Puzzle utilizando Busca em Largura (BFS) com poda de estados repetidos.

O objetivo é organizar oito peças numeradas em um tabuleiro 3×3, movimentando o espaço vazio (X), até alcançar a configuração final ordenada.

**Disciplina:** Tópicos Avançados em Inteligência Artificial I  
**Curso:** Tecnologia em Análise e Desenvolvimento de Sistemas — IFPE  
**Período:** 2026.2

## Algoritmo utilizado
Busca em Largura (BFS) com fila FIFO e controle de estados visitados, garantindo a solução com a menor quantidade de movimentos.

## Execução
Executar o arquivo `8_puzzle.py` utilizando Python 3:

`python3 8_puzzle.py`
