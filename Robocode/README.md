# Robocode — Robô de Combate

Desenvolvimento de um robô de combate utilizando Java e o ambiente Robocode.

O objetivo é implementar estratégias de movimentação, detecção de adversários, mira e disparo, utilizando os comandos e eventos disponibilizados pelo Robocode.

O robô utiliza estratégias para movimentar-se pela arena, identificar adversários pelo radar e reagir durante as batalhas.

**Disciplina:** Tópicos Avançados em Inteligência Artificial I  
**Curso:** Tecnologia em Análise e Desenvolvimento de Sistemas — IFPE  
**Período:** 2026.2

## Tecnologias utilizadas
- Java
- Robocode

## Execução
Importar ou compilar o código Java no ambiente Robocode e selecionar o robô para participar de uma batalha.
